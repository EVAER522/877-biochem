# 877 生化速刷

南航 877《生物医学化学》历年真题刷题页，807 题（2008—2026，缺 2019、2020 卷，2024—2026 为回忆版）。

## 功能

- 按**教材章节**（13 章 + 附录）和**考点**（64 个）筛题
- 范围筛选：全部 / 未掌握 / 只刷忘记 / 模糊待巩固 / 我的收藏
- 选择题点选项即时判对错；判断题选「对 / 错」
- 填空、名词解释、解答题：答案拆 2—3 个要点，**彩色标注 + 逐块遮盖**，点一下显示一块
- 每题答完自评：**忘记 / 模糊 / 熟悉**
- 收藏（★）、本轮统计、刷题日志
- 多用户日志：`logs/<用户名>.json`，可切换用户、记住上次用户
- 日志可写回 GitHub 仓库（需在 App 内配置 Fine-grained PAT）

## 部署

仓库 `EVAER522/877-biochem`，GitHub Pages 发布分支 `main`、目录 `/`。

访问：`https://evaer522.github.io/877-biochem/`

## 日志同步令牌

App 内「我的 → 同步令牌」填入 Fine-grained PAT：

- Repository access：Only select repositories → `EVAER522/877-biochem`
- Permissions：Contents = Read and write
- 令牌只保存在浏览器 localStorage，不写进代码、不进仓库

不配置令牌也能刷题，记录只存本机，可在「我的」里导出/导入 JSON 迁移。

## 数据来源

题目、答案与考点标签来自 877 历年真题整理（教材《生物化学》第二版，王冬梅、吕淑霞主编，科学出版社）。仅供本人复习使用。
